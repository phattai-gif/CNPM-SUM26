\subsubsection{System Architecture}
\label{subsubsec:system-architecture}

\begin{itemize}[leftmargin=1.5em, nosep]
    \item \textbf{Frontend:} The user interface is built using standard Web technologies (HTML/CSS, JS).
    \item \textbf{Backend:} Built with Flask (Python) following a RESTful API architecture. It uses SQLAlchemy as the ORM for database operations and implements Dependency Injection (via the dependency-injector library) for robust service management.
    \item \textbf{Database:} Uses PostgreSQL as the primary relational database system.
    \item \textbf{Third-party / Libraries:}
    \begin{itemize}[leftmargin=1.5em, nosep]
        \item \textbf{Cloudinary:} Cloud storage solution for managing image uploads.
        \item \textbf{Pillow:} Python Imaging Library used for internal image processing.
        \item \textbf{PyJWT \& Google-Auth:} Handles secure Authentication and Authorization.
        \item \textbf{APScheduler:} Manages and schedules background tasks (e.g., automated scoring, opening/closing contest rounds).
        \item \textbf{Flasgger / Swagger:} Automatically generates and serves interactive API documentation.
    \end{itemize}
\end{itemize}
